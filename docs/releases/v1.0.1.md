A small visual update to **!StayAlone**.

## What changed

- **New chat box** — the box where you type to your mascot now matches the rest of the app: rounded corners and shadow, a chat icon on the left, a borderless field and a round orange send button that lights up when there is text (click it or press Enter; Esc closes).

## Download

**[`dontStayAlone.exe`](https://github.com/4TyllaL/notStayAlone/releases/download/v1.0.1/dontStayAlone.exe)** — one file, the whole app (AI chat included). Download it and run it. Windows 10/11, 64-bit; no installer, settings live in `%APPDATA%\StayAlone` and are kept when you update.

> Why *dont*StayAlone? The app is **!StayAlone**, but GitHub strips the `!` from file names.

The binary is not code-signed yet, so SmartScreen may warn on first run (*More info → Run anyway*). GitHub shows its SHA-256 next to the download.

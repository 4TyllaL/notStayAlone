Cleaner screens: **!StayAlone** 1.2.8.

## What changed

- **Shorter plugin approval window:** the plugin's name and its own sentence, then one short line per permission (isolated from the rest of your PC, each folder it can read or write, internet or not), in orange when it needs your attention. The SHA-256 is shown as its first and last 8 characters.
- **Tidier *Security and privacy* card:** seven short lines (commit, SHA-256, protections, updates, API key, connections, plugins) and a one-line note.
- **Plugin test shows the whole reply:** the *Test* result in *Settings → Plugins* is no longer cut off; long replies keep their line breaks and scroll.

## Download

**[`dontStayAlone.exe`](https://github.com/4TyllaL/notStayAlone/releases/download/v1.2.8/dontStayAlone.exe)** — one file, the whole app (AI chat included). If you're on 1.1.x or 1.2.x, the app offers this update by itself. Windows 10/11, 64-bit; no installer, settings live in `%APPDATA%\StayAlone` and are kept when you update.

`dontStayAlone.exe.sig` is the update signature; the app downloads and checks it by itself, so you don't need it. `BUILDINFO.txt` is for anyone who wants to audit or rebuild the release (build a clean checkout at `C:\StayAloneBuild\src` with the toolchain it lists and you get the same SHA-256).

> Why *dont*StayAlone? The app is **!StayAlone**, but GitHub strips the `!` from file names.

The binary is not code-signed (Authenticode) yet, so SmartScreen may warn on first run (*More info → Run anyway*). GitHub shows its SHA-256 next to the download.

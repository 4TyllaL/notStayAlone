A safety-focused update to **!StayAlone**.

## What changed

- **The gallery is now mascots only.** Mascots are just drawings and lines in plain text — nothing that runs on your PC. Plugins (which are programs) are no longer offered in the gallery, and the app now accepts only `mascot.txt`, `phrases.txt` and `phrases_en.txt` from it; an item with any other file is rejected as a whole. Plugins you install yourself keep working as before.
- Small fix: the last untranslated label in the mascot maker.

## Download

**[`dontStayAlone.exe`](https://github.com/4TyllaL/notStayAlone/releases/download/v1.1.1/dontStayAlone.exe)** — one file, the whole app (AI chat included). If you're on 1.1.0, the app offers this update by itself. Windows 10/11, 64-bit; no installer, settings live in `%APPDATA%\StayAlone` and are kept when you update.

> Why *dont*StayAlone? The app is **!StayAlone**, but GitHub strips the `!` from file names.

The binary is not code-signed yet, so SmartScreen may warn on first run (*More info → Run anyway*). GitHub shows its SHA-256 next to the download.

A small fix to **!StayAlone**.

## What changed

- **Welcome screen:** picking a mascot now swaps the one on your desktop right away (and it says hi), instead of only after you finish the welcome.

## Download

**[`dontStayAlone.exe`](https://github.com/4TyllaL/notStayAlone/releases/download/v1.1.2/dontStayAlone.exe)** — one file, the whole app (AI chat included). If you're on 1.1.0 or 1.1.1, the app offers this update by itself. Windows 10/11, 64-bit; no installer, settings live in `%APPDATA%\StayAlone` and are kept when you update.

> Why *dont*StayAlone? The app is **!StayAlone**, but GitHub strips the `!` from file names.

The binary is not code-signed yet, so SmartScreen may warn on first run (*More info → Run anyway*). GitHub shows its SHA-256 next to the download.

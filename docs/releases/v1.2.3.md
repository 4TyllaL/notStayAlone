Safer updates for **!StayAlone**.

## What changed

- **Signed updates:** from now on, every update must carry an Ed25519 signature made with a key that never leaves the maintainer's PC. Even someone who took over the GitHub repository couldn't push an update to your app.
- **You confirm before installing:** after downloading and checking an update, the app shows what it verified (official source, SHA-256, signature, newer version) and what changed, and only installs if you say yes.

## Download

**[`dontStayAlone.exe`](https://github.com/4TyllaL/notStayAlone/releases/download/v1.2.3/dontStayAlone.exe)** — one file, the whole app (AI chat included). If you're on 1.1.x or 1.2.x, the app offers this update by itself. Windows 10/11, 64-bit; no installer, settings live in `%APPDATA%\StayAlone` and are kept when you update.

`dontStayAlone.exe.sig` is the update signature; the app downloads and checks it by itself, so you don't need it.

> Why *dont*StayAlone? The app is **!StayAlone**, but GitHub strips the `!` from file names.

The binary is not code-signed (Authenticode) yet, so SmartScreen may warn on first run (*More info → Run anyway*). GitHub shows its SHA-256 next to the download.

A hardened, verifiable build of **!StayAlone** 1.2.5.

## What changed

- **Control Flow Guard is back on.** Releases 1.1.x–1.2.4 were built on the maintainer's PC with the GNU toolchain, which can't emit CFG (their `DllCharacteristics` is `0x0160`: DEP and ASLR, no `GUARD_CF`). From 1.2.5 on, releases are built with a pinned MSVC toolchain (Rust 1.98.1) and ship with DEP, ASLR, high-entropy ASLR, Control Flow Guard, CET shadow-stack compatibility and a static C runtime. Thanks to the community review that spotted it.
- **Reproducible builds:** no timestamps, build dates or local paths go into the `.exe` any more (earlier builds carried the maintainer's user folder in a couple of dependency paths). The same commit with the same toolchain, MSVC and Windows SDK gives the same SHA-256.
- **`BUILDINFO.txt`** is published with every release: exact commit, Rust/Cargo/MSVC/Windows SDK versions, compiler and linker flags, and the SHA-256 of the `.exe` and `Cargo.lock`.
- **Security and privacy card** (*Settings → About*) now shows the commit the app was built from and the protections read from the running `.exe`'s own header (DEP · ASLR · high-entropy ASLR · CFG).

There's no GitHub build-provenance attestation yet: GitHub Actions is unavailable on this account, so releases are built locally. The Ed25519 update signature and `BUILDINFO.txt` cover that for now.

## Download

**[`dontStayAlone.exe`](https://github.com/4TyllaL/notStayAlone/releases/download/v1.2.5/dontStayAlone.exe)** — one file, the whole app (AI chat included). If you're on 1.1.x or 1.2.x, the app offers this update by itself. Windows 10/11, 64-bit; no installer, settings live in `%APPDATA%\StayAlone` and are kept when you update.

`dontStayAlone.exe.sig` is the update signature; the app downloads and checks it by itself, so you don't need it. `BUILDINFO.txt` is for anyone who wants to audit or rebuild the release.

> Why *dont*StayAlone? The app is **!StayAlone**, but GitHub strips the `!` from file names.

The binary is not code-signed (Authenticode) yet, so SmartScreen may warn on first run (*More info → Run anyway*). GitHub shows its SHA-256 next to the download.

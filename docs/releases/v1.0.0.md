The first stable release of **!StayAlone** — a pixel-art pet that keeps you company on your Windows desktop. Rust on the raw Win32 API: ~650 KB, a few MB of RAM, ~0% CPU.

> The app's interface is in Brazilian Portuguese.

## Download

**[`dontStayAlone.exe`](https://github.com/4TyllaL/notStayAlone/releases/download/v1.0.0/dontStayAlone.exe)** — one file, the whole app (AI chat included). Download it and run it. Windows 10/11, 64-bit; no installer, settings live in `%APPDATA%\StayAlone`.

> Why *dont*StayAlone? The app is **!StayAlone**, but GitHub strips the `!` from file names.

The binary is not code-signed yet, so SmartScreen may warn on first run (*More info → Run anyway*). GitHub shows its SHA-256 next to the download.

## What's inside

- **Four mascots** — Calcifer (cat), Lance (dog), Zezé (bunny) and Jujubs (dinosaur), each with their own lines.
- **Companionship** — notices when you leave and return, reminders counted only while you use the PC (water, stretch, eyes, plus your own), affection hearts, daily summary, focus timer.
- **Play** — drag and throw it, treats, ball; reacts to low battery and long typing streaks; hides during full-screen apps.
- **New panel** — right-click the mascot or click the tray icon: quick actions, mascot picker, size selector, silence/hide toggles.
- **Redesigned settings** — sidebar with a live preview of your mascot, cards, rounded buttons.
- **Mascot maker** — draw one 16×16 pose and every animation is generated; or describe it and let the AI draw.
- **AI chat** — any OpenAI-compatible API, Gemini by default (also OpenAI, OpenRouter, local Ollama).
- **Plugins** — your own `.exe` or PowerShell scripts that speak on a schedule or answer the chat; off by default, pinned by SHA-256.

## Security

Reviewed in the style of a Common Criteria Security Target ([SECURITY.md](https://github.com/4TyllaL/notStayAlone/blob/main/SECURITY.md)):
API key in the Windows Credential Manager (never in files or environment variables), HTTPS-only with TLS 1.2+ and no redirects, no pointers in window messages, bounded inputs everywhere, system DLLs loaded from System32 only, ASLR/DEP, runs as a regular user.

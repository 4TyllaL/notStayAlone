A small fix to **!StayAlone**.

## What changed

- **Dark mode:** the column titles of the lists (Reminders, Plugins and Gallery) were dark on a dark background. They now use the light text color.

## Download

**[`dontStayAlone.exe`](https://github.com/4TyllaL/notStayAlone/releases/download/v1.2.1/dontStayAlone.exe)** — one file, the whole app (AI chat included). If you're on 1.1.x or 1.2.0, the app offers this update by itself. Windows 10/11, 64-bit; no installer, settings live in `%APPDATA%\StayAlone` and are kept when you update.

> Why *dont*StayAlone? The app is **!StayAlone**, but GitHub strips the `!` from file names.

The binary is not code-signed yet, so SmartScreen may warn on first run (*More info → Run anyway*). GitHub shows its SHA-256 next to the download.

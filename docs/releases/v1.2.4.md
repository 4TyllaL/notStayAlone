Security you can see: **!StayAlone** 1.2.4.

## What changed

- **Security and privacy card** in *Settings → About*: the SHA-256 of the running `.exe` (compare it with GitHub's), how updates are checked, where your API key is stored, which services the app talks to, whether it starts with Windows and how many plugins can run programs. It also says what's still missing (no Authenticode yet).
- **Plugins are contained:** every plugin (and every helper process of the app) now runs in a Windows Job Object. It can't start other programs, read or change the clipboard, touch other windows or system settings; it's capped at 512 MB and closes with the app.
- **Honest plugin approval:** turning on a plugin now says plainly that it has *full access* (it runs with your account's permissions and can read your files and use the internet), lists what the app limits and shows the SHA-256 you're approving.
- Speech bubbles expose their text to screen readers.
- The UI smoke test (`tools/smoke.ps1`) no longer fails at random: it now simulates use of the PC the way the app expects, identifies each bubble by its text, and checks the plugin approval question.

## Download

**[`dontStayAlone.exe`](https://github.com/4TyllaL/notStayAlone/releases/download/v1.2.4/dontStayAlone.exe)** — one file, the whole app (AI chat included). If you're on 1.1.x or 1.2.x, the app offers this update by itself. Windows 10/11, 64-bit; no installer, settings live in `%APPDATA%\StayAlone` and are kept when you update.

`dontStayAlone.exe.sig` is the update signature; the app downloads and checks it by itself, so you don't need it.

> Why *dont*StayAlone? The app is **!StayAlone**, but GitHub strips the `!` from file names.

The binary is not code-signed (Authenticode) yet, so SmartScreen may warn on first run (*More info → Run anyway*). GitHub shows its SHA-256 next to the download.

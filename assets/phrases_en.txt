# !StayAlone — mascot lines (English)
#
# One line per row, grouped by [topic] (the topic names stay in Portuguese).
# The mascot picks one at random (never the same twice in a row).
# Lines starting with '#' are comments.
#
# Any line can use {nome} (the mascot's name). In [resumo]:
#   {juntos}  time you spent together today (e.g. 3h12min)
#   {pausas}  e.g. "2 breaks" / "no breaks"
#   {agua}    e.g. "3 glasses" / "no water"
#
# Each mascot can have its own lines (phrases_en.txt in its folder),
# which replace these only in the topics it defines.
#
# Tip: put an edited copy named "phrases_en.txt" next to
# dontStayAlone.exe to change the default lines without recompiling.
